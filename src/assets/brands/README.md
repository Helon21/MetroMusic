Os logotipos são marcas registradas dos respectivos donos. O MetroMusic é um projeto
independente e não tem vínculo, patrocínio ou aprovação de nenhuma dessas empresas.
Antes de distribuir o app, confira as diretrizes de uso de marca de cada serviço.
